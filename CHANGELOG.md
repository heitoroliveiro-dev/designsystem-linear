# Changelog

Formato baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/). Versionamento [SemVer](https://semver.org/lang/pt-BR/) (ver `docs/09-governanca.md`).

## [1.0.0] — 2026-10-15

### Adicionado
- Pipeline de tokens W3C DTCG 2025.10: sementes → escalas OKLCH de 12 passos → semânticos → CSS + `@theme` Tailwind v4.
- Verificação automática de contraste WCAG 2.2 AA no build (dark, light e alto contraste).
- Modos dark (padrão), light e alto contraste (`data-contrast="high"`).
- Componentes: Alert, Avatar, Badge, Button, Card, Checkbox, Command, Dialog, Dropdown Menu, Input, Kbd, Label, Popover, Radio Group, Select, Separator, Skeleton, Sonner, Spinner, Switch, Table, Tabs, Textarea, Tooltip.
- Efeitos em CSS puro: GlowCard, BorderBeam, Background (grid, dots, spotlight) e utilitários `glow`, `highlight-top`, `text-gradient`.
- Documentação navegável (Next.js) e guias em `docs/`.
- `AGENTS.md` com as regras do sistema para assistentes de IA.
